# Post-deploy QA tests

Generated by the [qa-audit](https://github.com/artemhorbenko/qa-audit) Claude skill. Every check lives in `qa-suite.json`; `qa.spec.js` is generic and does not need editing.

```
npm install
npx playwright install chromium
npx playwright test                 # all checks, Chromium
BROWSERS=all npx playwright test    # plus Firefox and WebKit (Safari engine)
QA_ONLY=T03,T04 npx playwright test # only some checks
npx playwright show-report qa-report
```

Run it after every deploy. A failing check names what broke; screenshots and traces of failures are in `test-results/`.

**Safety.** The tests never submit forms, payments or messages. Form checks read the fields and fire a synthetic "sent" event in the browser to see whether analytics reacts; nothing reaches the server.

**Politeness.** Requests go one at a time with `delayMs` between them (default 1500 ms). If the host answers 429/503 or shows a captcha, the check is skipped as "not checked" instead of failing; raise `delayMs` or allowlist the runner's IP. Never solve captchas automatically.

**Check types** (`type` in `qa-suite.json`): `status`, `redirect`, `ga4_tag`, `click_event`, `form_event`, `form_fields`, `text`, `no_text`, `ui_language`, `console_clean`, `no_h_scroll`, `page_links`, `sitemap`, `axe`, `meta`. Add `"skip": true` to park a check.
